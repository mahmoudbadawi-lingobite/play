Put your own 3D models (.glb files) for the Style Store in this folder.

On GitHub: open the "public" folder, open "models", click Add file > Upload files, drop your .glb file, and Commit.
After the site rebuilds, the file's address is:
  https://YOUR-NAME.github.io/play/models/your-file.glb
Paste that address in the Style Store Admin page under "My own 3D model (.glb)".
Tip: keep each file under 2 MB. Free models: search for "low poly glb".
